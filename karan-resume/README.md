# karan-resume

## Stack

- React 18 + TypeScript
- Vite
- MUI (Material UI v7)
- Emotion
- React Router v6

## Local development

```bash
yarn install    # install dependencies
yarn dev        # start dev server at http://localhost:5173
```

## Build

```bash
yarn build      # compiles TypeScript and bundles to dist/
yarn preview    # serve the dist/ build locally to verify
```

## Other commands

```bash
yarn lint            # ESLint
yarn format          # Prettier (write)
yarn test            # Vitest (watch mode)
yarn test:run        # Vitest (single run)
yarn test:coverage   # Vitest with coverage report → outputs coverage/coverage-summary.json
yarn deploy          # build + deploy to GitHub Pages
```

## Static data

Two JSON files in `src/data/` are generated by GitHub Actions and baked into the build:

| File | Generated by | Schedule |
|---|---|---|
| `pulse.json` | `scripts/summarize.py` | Every 3 days |
| `stats.json` | `scripts/generate_stats.py` | Weekly (Monday) |

`summarize.py` calls the GitHub API to fetch recent push events, extracts commit messages and file-level diffs (+/- line counts per file), then calls GitHub Models (Mistral) to generate a short natural-language summary.

`generate_stats.py` reads Vitest's `coverage-summary.json` and the latest Lighthouse CI report to produce coverage percentages and Lighthouse scores (accessibility, performance, LCP, CLS).

## Deploy

Deployment is automatic via the GitHub Actions workflow at `.github/workflows/main.yml`. Any push to `main`:

1. Installs dependencies with Yarn
2. Builds with Vite (`yarn build`)
3. Writes a `CNAME` file with `karanshukla.ca` into the build output
4. Publishes to the `gh-pages` branch using `peaceiris/actions-gh-pages`

GitHub Pages serves the `gh-pages` branch at the custom domain.
